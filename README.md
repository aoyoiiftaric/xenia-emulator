## Overview

Xenia is the most advanced and compatible Xbox 360 emulator available, capable of running hundreds of Xbox 360 commercial games on Windows at full or near-full speed. Built on a high-performance GPU-accelerated architecture with a custom JIT compiler, Xenia supports Direct3D-to-Vulkan translation and continues to improve compatibility through active community development.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Xenia Emulator** delivers the features you need in a clean, intuitive package.
